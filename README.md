# CRYSTAL AUTO — премиальный сайт химчистки салона

Кинематографичный одностраничный сайт детейлинг-студии химчистки салона автомобиля.
Тёмная ахроматичная эстетика, крупная типографика, full-bleed видео и интерактивная
галерея «До / После».

**Стек:** чистый HTML + CSS + JavaScript. **Без сборки.** Никаких `npm`, Vite, React.

---

## Как открыть

**Вариант 1 — просто открыть файл.** Двойной клик по `index.html` (откроется в браузере).

**Вариант 2 — локальный сервер** (рекомендуется: корректнее работают видео и карта):

```bash
# Python 3
python3 -m http.server 8000
# затем открыть http://localhost:8000

# или Node
npx serve .
```

> Шрифты (Fraunces + Inter) подключаются с Google Fonts по CDN. Без интернета сайт
> остаётся рабочим — заголовки/текст деградируют на системные serif/sans-serif.

## Где менять контент

Почти всё редактируется в одном файле — **`assets/js/config.js`**:
бренд, контакты, навигация, услуги, цифры, процесс, аргументы, отзывы, FAQ,
параметры формы и карты. Значения с пометкой `[PLACEHOLDER]` — временные заглушки,
их нужно заменить на реальные данные.

---

## Фотографии «До / После»

Реальные фото работ **уже добавлены** в `assets/img/before-after/` (оптимизированы в JPG).
Чтобы заменить/добавить пары — положите файлы с такими именами
(горизонтальные ~3:2, JPG) и при необходимости поправьте `config.js → beforeAfter`:

| Работа            | «До»               | «После»           |
|-------------------|--------------------|-------------------|
| Сиденье           | `seat-before.jpg`  | `seat-after.jpg`  |
| Пол / ковёр       | `floor-before.jpg` | `floor-after.jpg` |
| Карта двери       | `door-before.jpg`  | `door-after.jpg`  |

Пары и подписи настраиваются в `config.js → beforeAfter`. Если файла нет — на его
месте показывается аккуратная заглушка «Фото скоро появится».

## Видео

Лежат в `assets/video/`. Имена отражают роль на странице:

| Файл                | Где используется               |
|---------------------|--------------------------------|
| `hero-desktop.mp4`  | Фон главного экрана (desktop)   |
| `hero-mobile.mp4`   | Фон главного экрана (вертикаль) |
| `reel-vertical.mp4` | Секция «Процесс»                |
| `atmosphere.mp4`    | Атмосферная вставка             |
| `process-02.mp4`    | Блок записи                     |
| `process-01/03`, `showcase` | Резерв для замены       |

Чтобы заменить ролик — просто положите свой файл с тем же именем. Видео
автоматически ставятся на паузу, когда уходят из зоны видимости (экономия ресурсов).

## Яндекс.Карта

Карта в секции «Контакты» **уже настроена** на координаты студии в Златоусте
(`55.149092, 59.679676`) через встраиваемый виджет Яндекс.Карт — **без API-ключа.**
Настройки — в `config.js → map`. Чтобы сдвинуть точку, поменяйте `coords` и `embedUrl`.

**Вариант 1 — без ключа (используется сейчас).**
Готовый виджет `https://yandex.ru/map-widget/v1/?ll=ДОЛГОТА,ШИРОТА&z=16&pt=ДОЛГОТА,ШИРОТА,pm2rdm`
в `map.embedUrl`. Можно также собрать карту в
[Конструкторе Яндекс.Карт](https://yandex.ru/map-constructor/) и вставить его ссылку.

**Вариант 2 — JavaScript API (нужен ключ).**
1. Получите ключ в [кабинете разработчика Яндекса](https://developer.tech.yandex.ru/).
2. Укажите `map.apiKey` и `map.coords` (`[широта, долгота]`) в `config.js`.
3. Для продакшена ключ лучше держать вне публичного репозитория (отдельный
   незакоммиченный `config.local.js` или подстановка на этапе деплоя).

Пока ничего не задано — отображается стилизованная заглушка с адресом.

## Бронирование (форма записи)

Форма во `frontend-ready`-режиме. Поведение задаётся в `config.js → booking`:

- **`endpoint` пустой (по умолчанию):** демо-режим — заявка валидируется, показывается
  подтверждение, данные пишутся в консоль; при наличии `whatsapp`/`telegram` в
  контактах предлагается продублировать заявку в мессенджер.
- **`endpoint` задан:** заявка уходит `POST`-запросом (JSON) на ваш URL — это может быть
  бэкенд, вебхук CRM (Bitrix24, amoCRM), Telegram-бот, Google Apps Script и т.п.

Отправляемые поля: `name, phone, service, car, time, comment, page, ts`.

## Доступность и адаптивность

- Семантическая разметка, `aria`-атрибуты, фокус-стили, skip-link, `prefers-reduced-motion`.
- Полноценная работа на desktop / tablet / mobile (мобильное меню, адаптивные сетки).
- 100% ахроматичная палитра по дизайн-системе — без случайных цветов.

## Замена бренда

Название студии задаётся в `config.js → brand.name` и подставляется в шапку, футер,
тексты и заголовок страницы (`<title>` правится в `index.html`).
